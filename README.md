# САМ ВКО — Кроссплатформенный Трей-Агент (Windows & Linux)

Ветка: `feature/tray-agent`  
Назначение: **Клиентское приложение в системном трее** для школьных компьютеров, осуществляющее сбор и отправку метрик качества интернет-соединения в единую систему мониторинга ВКО.

---

## 📌 Что реализовано в этой ветке

1. 🖥 **Кроссплатформенность (Windows & Linux)**:
   - **Linux**: поддержка X11 / Wayland (через AppIndicator / `pystray`), автозапуск через XDG Autostart (`~/.config/autostart/vko-agent.desktop`).
   - **Windows**: нативная интеграция с Win32 Tray Icon, автозапуск через реестр (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
2. 🟢 **Динамическая иконка в трее**:
   - Автоматически меняет цвет в зависимости от состояния сети:
     - 🟢 **Зелёный** — отличное качество (SLA соблюдается).
     - 🟡 **Жёлтый** — деградация связи (скорость < 10 Мбит/с или потери > 5%).
     - 🔴 **Красный** — соединение отсутствует или сервер недоступен.
     - ⚪ **Серый** — первичная инициализация / измерение.
3. 📊 **Графический интерфейс (GUI)**:
   - **Окно статуса** (по клику на иконку в трее): текущие показатели Download / Upload, Ping, Packet Loss, размер локальной очереди, статус синхронизации.
   - **Диалог первичной настройки (Enrollment)**: при первом старте запрашивает адрес сервера, код школы и секретный ключ развёртывания.
4. 💾 **Офлайн-спул (Smart Sync / SQLite)**:
   - При отключении интернета замеры не теряются, а накапливаются в локальной базе `~/.vko-agent/spool.sqlite`.
   - При восстановлении связи агент пакетами (batch) выгружает накопленные данные с адаптивным backoff и защитой от Thundering Herd.
5. 📦 **Сборка в один исполняемый файл (Standalone)**:
   - Скрипты `build_linux.sh` (ELF-бинарник) и `build_windows.bat` (`.exe`) для работы на машинах **без установленного Python**.

## 🚀 Как запустить на Linux

### Вариант 1: Быстрый запуск через Python (разработка и тест)

Требуется Python 3.9+ и графическая среда (GNOME, KDE, XFCE и др.):

```bash
cd agent

# 1. Установка зависимостей трея и замеров
pip install -r requirements-tray.txt
pip install speedtest-cli

# 2. Запуск приложения в трее
python tray_agent.py
```

При первом запуске появится графическое окно настройки (см. раздел [Первичная настройка](#первичная-настройка)).

### Вариант 2: Сборка в один исполняемый файл (для установки в школах)

На целевой Linux-машине не потребуется Python:

```bash
cd agent

# Собрать бинарник через PyInstaller
bash build_linux.sh
```

Готовый файл появится в `agent/dist/SAM-VKO-Agent`.

Запуск:
```bash
chmod +x dist/SAM-VKO-Agent
./dist/SAM-VKO-Agent
```

Установка в автозагрузку пользователя:
```bash
./dist/SAM-VKO-Agent --install-autostart
```

## 🪟 Как запустить на Windows

### Вариант 1: Быстрый запуск через Python

Требуется Python 3.9+ (при установке Python обязательно отметьте галочку *"Add Python to PATH"*):

Откройте командную строку (`cmd`) или PowerShell:

```cmd
cd agent

REM 1. Установка зависимостей
pip install -r requirements-tray.txt
pip install speedtest-cli

REM 2. Запуск агента
python tray_agent.py
```

В области уведомлений (возле часов) появится иконка агента с буквой «В».

### Вариант 2: Сборка в один файл `.exe` (для распространения)

На машине с Windows запустите:

```cmd
cd agent
build_windows.bat
```

После завершения сборки готовый файл будет в папке `agent\dist\SAM-VKO-Agent.exe`.

- **Запуск:** двойной клик по `SAM-VKO-Agent.exe`.
- **Включение автозагрузки:**
  ```cmd
  dist\SAM-VKO-Agent.exe --install-autostart
  ```
  *(добавляет команду в автозапуск реестра Windows без необходимости прав администратора)*.

## ⚙️ Первичная настройка и подключение к серверу

При первом запуске агент откроет окно регистрации:

| Поле | Пример значения | Где взять / Описание |
|---|---|---|
| **Адрес сервера** | `http://localhost:8000` | Адрес бэкенда мониторинга (или внешний IP сервера) |
| **Код школы** | `VKO-UK-001` | Официальный код организации образования в системе |
| **Код развёртывания** | `vko-deploy-2026` | Секрет из веб-панели: **Управление → Школы → Код агента** |
| **Кабинет / ПК** | `Кабинет информатики №1 (ПК-04)` | Произвольное имя кабинета и рабочего места |

После нажатия кнопки **«Подключить»** агент:
1. Выполнит запрос `POST /api/agent/enroll` к серверу.
2. Получит постоянный JWT/Device-токен и сохранит его в `~/.vko-agent/state.json`.
3. Начнёт регулярный цикл мониторинга и спрячется в системный трей.

## 📋 Управление через трей

Клик правой кнопкой мыши по иконке в трее открывает контекстное меню:

- 📊 **Показать статус** — открывает окно с текущими метриками скорости, задержки, потерь пакетов и состоянием офлайн-буфера.
- 🌐 **Открыть панель** — открывает дашборд системы в браузере (`http://localhost:5173`).
- ⚙️ **Настройки** — позволяет перенастроить параметры подключения.
- 🔄 **Перезапустить агент** — принудительный перезапуск цикла измерений.
- ✖ **Завершить** — корректный выход из приложения.

## 🧪 Тестирование в связке с бэкендом и фронтендом

Чтобы протестировать полный контур (Бэкенд + Веб-панель + Трей-агент) на одной машине:

1. **Запустите бэкенд:**
   ```bash
   cd backend
   source venv/bin/activate   # если используется venv
   python main.py
   # Бэкенд слушает на http://localhost:8000
   ```

2. **Запустите веб-интерфейс:**
   ```bash
   cd frontend
   npm run dev
   # Веб-панель доступна на http://localhost:5173
   ```

3. **Запустите трей-агент:**
   ```bash
   cd agent
   python tray_agent.py
   ```
   Укажите сервер `http://localhost:8000`, код школы `VKO-UK-001`, секрет развёртывания из базы/панели. После регистрации замеры с вашего ПК сразу отобразятся в карточке школы на карте!

## 📁 Структура файлов агента в системе

Все рабочие файлы агент хранит в домашней директории пользователя:
- **Linux:** `~/.vko-agent/`
- **Windows:** `C:\Users\<Имя_Пользователя>\.vko-agent\`

Содержимое:
```
.vko-agent/
├── config.json     # URL сервера, код школы, кабинет
├── state.json      # Идентификатор устройства и токен авторизации
├── spool.sqlite    # Локальная очередь замеров при отсутствии сети
└── agent.log       # Лог работы и ошибок
```

## 🔀 Связь с веткой `main`

- Ветка **`main`**: ядро системы — бэкенд (FastAPI, ML-диагностика "Виновник", генератор претензий), база данных (181 школа ВКО с точными координатами), веб-панель (React, Mapbox GL) и консольный агент.
- Ветка **`feature/tray-agent`**: специализированное GUI/Трей приложение для клиентских ПК школ на Windows и Linux.
