# САМ ВКО — Трей-агент мониторинга (Windows и Linux)

Ветка: `feature/tray-agent`  
Назначение: клиентское фоновое приложение для рабочих мест в организациях образования. Выполняет инструментальные замеры качества интернет-соединения, отображает статус в системном трее и передаёт телеметрию на сервер мониторинга.

---

## 1. Возможности приложения

- **Кроссплатформенность**:
  - Linux: интеграция через X11 / AppIndicator (`pystray`), автозапуск через XDG Autostart (`~/.config/autostart/vko-agent.desktop`).
  - Windows: нативная иконка в области уведомлений Win32, автозапуск через пользовательский реестр (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
- **Индикация состояния**:
  - Зеленый: параметры связи в пределах нормы SLA.
  - Желтый: деградация канала (скорость ниже 10 Мбит/с или потери пакетов свыше 5%).
  - Красный: отсутствие связи или недоступность сервера.
  - Серый: начальная инициализация или выполнение замера.
- **Интерфейс пользователя**:
  - Окно статуса: текущие показатели входящей/исходящей скорости, задержки (ping), потерь пакетов, состояние локальной очереди.
  - Окно первичной настройки (Enrollment): графический ввод параметров при первом запуске.
  - Контекстное меню трея: вызов статуса, переход в веб-панель, настройки, принудительный замер, выход.
- **Офлайн-буфер (Smart Sync)**:
  - При потере связи замеры сохраняются в локальную базу SQLite (`~/.vko-agent/spool.sqlite`).
  - При восстановлении канала выполняется пакетная передача с защитой от лавинной нагрузки (случайная задержка).
- **Автономная сборка**:
  - Возможность компиляции в единый исполняемый файл (`.exe` для Windows, бинарный ELF для Linux), работающий без установки интерпретатора Python на целевом ПК.

## 2. Запуск на Linux

### Вариант А. Запуск через Python (разработка и тестирование)

Требования: Python 3.9+, установленная графическая оболочка (X11 / Wayland).

```bash
cd agent

# Установка зависимостей интерфейса и замеров
pip install -r requirements-tray.txt
pip install speedtest-cli

# Запуск
python tray_agent.py
```

При первом запуске откроется окно конфигурации.

### Вариант Б. Сборка в один бинарный файл

Для тиражирования на школьные компьютеры без установленного Python:

```bash
cd agent
bash build_linux.sh
```

Результат сборки помещается в `agent/dist/SAM-VKO-Agent`.

Запуск:
```bash
chmod +x dist/SAM-VKO-Agent
./dist/SAM-VKO-Agent
```

Установка в автозагрузку текущего пользователя:
```bash
./dist/SAM-VKO-Agent --install-autostart
```

Отключение автозагрузки:
```bash
rm ~/.config/autostart/vko-agent.desktop
```

## 3. Запуск на Windows

### Вариант А. Запуск через Python

Требования: Python 3.9+ (с флагом Add Python to PATH).

В командной строке (`cmd` или PowerShell):

```cmd
cd agent

rem Установка зависимостей
pip install -r requirements-tray.txt
pip install speedtest-cli

rem Запуск приложения
python tray_agent.py
```

Иконка появится в области уведомлений панели задач (рядом с часами).

### Вариант Б. Сборка в исполняемый файл (.exe)

На компьютере с Windows выполните:

```cmd
cd agent
build_windows.bat
```

Исполняемый файл создаётся по пути `agent\dist\SAM-VKO-Agent.exe`.

- Запуск: двойной клик по `SAM-VKO-Agent.exe`.
- Установка в автозагрузку Windows:
  ```cmd
  dist\SAM-VKO-Agent.exe --install-autostart
  ```
  Команда прописывает путь в ветку реестра `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` без запроса прав администратора.

## 4. Настройка подключения

При первом старте открывается окно регистрации:

| Параметр | Пример | Назначение |
|---|---|---|
| Адрес сервера | `http://localhost:8000` | URL бэкенда системы мониторинга |
| Код школы | `VKO-UK-001` | Идентификатор организации из реестра |
| Код развёртывания | `vko-deploy-2026` | Секретный ключ из раздела «Управление» панели |
| Кабинет / ПК | `Кабинет информатики №1` | Наименование помещения и рабочего места |

После сохранения агент регистрируется на сервере (`POST /api/agent/enroll`), получает авторизационный токен и начинает цикл периодических измерений.

Консольный режим без графического интерфейса:
```bash
python tray_agent.py --console
```
В этом режиме параметры считываются напрямую из `~/.vko-agent/config.json`.

## 5. Файловая структура агента

Все данные профиля хранятся локально:
- Linux: `~/.vko-agent/`
- Windows: `%USERPROFILE%\.vko-agent\`

```
.vko-agent/
|-- config.json     # сетевые настройки и реквизиты школы
|-- state.json      # идентификатор устройства и рабочий JWT-токен
|-- spool.sqlite    # очередь неотправленных замеров
`-- agent.log       # локальный журнал событий
```

## 6. Связь с основной веткой

- Ветка `main`: серверная часть (FastAPI), база данных 181 организации ВКО, веб-интерфейс оператора (React, Mapbox GL), ML-диагностика («Виновник») и генерация досудебных претензий.
- Ветка `feature/tray-agent`: клиентское приложение системного трея для конечных ПК.
