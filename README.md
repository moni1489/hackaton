# САМ ВКО — система автономного мониторинга качества интернет-соединения

Мониторинг каналов связи организаций образования Восточно-Казахстанской области:
**карта области → карточка школы → отдельный ПК-уровень прослеживания**.

**181 организация ВКО · реальные GPS-координаты из OpenStreetMap · ML-диагностика**

---

## 1. Что сделано

### 🗺 Карта и данные
- **181 реальная школа ВКО** — координаты импортированы из OpenStreetMap (Overpass API)
- Покрытие: г. Усть-Каменогорск, г. Семей, г. Риддер, г. Курчатов, Зайсанский, Катон-Карагайский,
  Курчумский, Тарбагатайский, Уланский, Глубоковский, Шемонаихинский, Самарский, Алтайский, Аягозский, Бескарагайский районы
- Карта зафиксирована на ВКО (Mapbox GL, центр — Усть-Каменогорск, `maxBounds` не даёт улететь в Россию)
- Российские школы (Змеиногорск, Алтайский край), случайно попавшие в bbox, удалены

### 🤖 ML-диагностика
- Атрибуция «кто виноват»: провайдер / ЛВС школы / отдельный ПК / магистраль
- Прогноз пробоя SLA на 6 часов вперёд
- Страница диагностики с доказательной базой по каждой организации

### 🔐 Авторизация и роли
- Логин-страница, JWT-токены
- Роли: `admin`, `operator`, `school`, `provider`

### 📊 Интерфейс
- Карта области, реестр школ, ПК-агенты, инциденты, управление
- Боковой навбар (Rail), карточка школы, карточка устройства
- Графики скорости/задержки/потерь по времени

### 📄 Претензии и PDF
- AI-генерация досудебной претензии (Gemini + юридический шаблон-fallback)
- PDF-акт фиксации нарушения SLA (ReportLab)

### ⚡ Smart Sync
- Агент накапливает замеры офлайн в локальный SQLite-спул
- При восстановлении связи выгружает пакетами со случайной задержкой (защита от Thundering Herd)

## 2. Архитектура

```
agent/                  ПК-агент (Python): замеры, локальный спул, Smart Sync
backend/
  app/
    config.py           настройки через переменные окружения
    database.py         PostgreSQL (прод) / SQLite (демо)
    cache.py            Redis + in-memory fallback
    security.py         JWT, mTLS, RBAC, неизменяемый аудит
    models.py           School · Device · Measurement · Incident · User · AuditLog
    routers/
      auth.py           Auth API    — вход, роли, журнал аудита
      agent.py          Agent API   — регистрация ПК, приём замеров, Smart Sync
      web.py            Web API     — дашборд, карта, карточка школы
      admin.py          Admin API   — агенты, пользователи, коды развёртывания
      ai.py             AI API      — претензии и PDF-акты SLA
      ml.py             ML API      — атрибуция и прогноз
    services/
      status.py         правила классификации качества и SLA
      smart_sync.py     очередь офлайн-догрузок
      reports.py        генерация PDF (ReportLab)
      ml/               «Виновник» — машинное обучение
  bootstrap.py          миграция схемы, демо-данные, обучение моделей
  import_vko_osm.py     импорт реальных школ из OpenStreetMap
frontend/               React 19 + Vite + Mapbox GL + Recharts
```

## 3. Безопасность

| Мера | Реализация |
|---|---|
| HTTPS/TLS | обязателен, HSTS вне debug-режима |
| Аутентификация устройства | JWT с SHA-256 отпечатком оборудования |
| Защита от подмены ID | `school_id` из БД, не из тела запроса |
| mTLS | клиентский сертификат (`REQUIRE_MTLS=true`) |
| RBAC | admin · operator · school · provider |
| Rate limiting | 120 req/min агент, 600 пользователь |
| Аудит | append-only журнал со сцепленными SHA-256 хэшами |

## 4. Запуск

```bash
# 1. Backend
cd backend
pip install -r requirements.txt
python bootstrap.py        # миграция + демо-данные (идемпотентно)
python main.py             # → http://localhost:8000/docs

# 2. Frontend
cd frontend
npm install
npm run dev                # → http://localhost:5173

# 3. ПК-агент (консольный режим)
cd agent
pip install -r requirements.txt
export VKO_SCHOOL_CODE=VKO-UK-001
export VKO_ENROLL_SECRET=<код из раздела «Управление»>
python agent.py
```

### Переменные окружения (продакшн)

```bash
DATABASE_URL=postgresql+psycopg://user:pass@db:5432/vko
REDIS_URL=redis://cache:6379/0
JWT_SECRET=<секрет>
GENAI_TOKEN=<ключ Gemini>
DEBUG=false
```

### Демо-доступы

| Логин | Пароль | Роль |

| `admin@vko.edu.kz` | `admin123` | Администратор — вся область |

## 5. ML-диагностика «Виновник»

Главный аргумент в споре с провайдером — граница поражения:

| Что показывают замеры | Вердикт | Ответственный |
|---|---|---|
| 1 ПК из N, остальные в норме | Отдельный ПК / линк | Сисадмин школы |
| Все ПК школы, соседние ок | Шлюз / ЛВС школы | Обслуживающая организация |
| Все школы провайдера в районе | Узел провайдера | Провайдер |
| Все провайдеры района | Магистраль / энергоснабжение | Магистральный оператор |

Вердикт подставляется в PDF-акт и в досудебную претензию автоматически.

## 6. Трей-агент (Windows / Linux) в системном трее

Полноценное приложение с иконкой в трее, окном статуса и диалогом подключения находится в ветке **`feature/tray-agent`**:

```bash
# Переключение на ветку трей-агента
git checkout feature/tray-agent
```

### Быстрый запуск агента:

**На Linux:**
```bash
cd agent
pip install -r requirements-tray.txt
pip install speedtest-cli
python tray_agent.py
# Или сборка в один бинарник: bash build_linux.sh
```

**На Windows:**
```cmd
cd agent
pip install -r requirements-tray.txt
pip install speedtest-cli
python tray_agent.py
# Или сборка в .exe: build_windows.bat
```

> Подробная инструкция по сборке, автозагрузке и настройке — в `README.md` ветки `feature/tray-agent`.

## 7. Данные

**Источник координат:** OpenStreetMap (Overpass API) — реальные GPS-точки школ ВКО.

**Метрики:** текущие значения (скорость, ping, loss) — тестовые, генерируются симулятором.
В продакшене заменяются реальными замерами агентов.

**Официальный реестр:** полный список 342 организаций доступен на [data.egov.kz](https://data.egov.kz)
(требуется API-ключ). При наличии ключа — импорт занимает 5 минут.
