# САМ ВКО — Трей-агент (Windows и Linux)

Приложение в системном трее для сбора данных о качестве интернета на школьном ПК.
Работает в фоне, отправляет замеры на сервер, хранит данные офлайн при обрыве связи.

---

## Возможности

- Иконка в трее — меняет цвет в зависимости от состояния связи (зеленый / желтый / красный).
- Окно статуса — показывает текущие Download, Upload, Ping, Packet Loss.
- Диалог настройки — адрес сервера, код школы, код развертывания.
- Speedtest — реальный замер через speedtest-cli.
- Офлайн-спул — при обрыве замеры сохраняются локально в SQLite, затем автоматически выгружаются.
- Автозапуск — автоматическое добавление в автозагрузку системы.
- Быстрый доступ к панели — открытие веб-интерфейса в браузере.

## Быстрый старт (без сборки)

### Требования
- Python 3.9+
- speedtest-cli

### Linux

```bash
cd agent

# Установить зависимости
pip install -r requirements-tray.txt
pip install speedtest-cli

# Запустить
python tray_agent.py
```

### Windows

```cmd
cd agent

rem Установить зависимости
pip install -r requirements-tray.txt
pip install speedtest-cli

rem Запустить
python tray_agent.py
```

При первом запуске откроется окно настройки:

| Поле | Значение |
|---|---|
| Адрес сервера | `http://localhost:8000` (или IP сервера) |
| Код школы | Например `VKO-UK-001` |
| Код развертывания | Получить в панели: Управление -> Школы -> Код агента |
| Кабинет | `Кабинет информатики №1` |

## Сборка в один файл (без Python на целевой машине)

### Linux (бинарный файл ELF)

```bash
cd agent
bash build_linux.sh
# Результат: dist/SAM-VKO-Agent
```

Запуск:
```bash
chmod +x dist/SAM-VKO-Agent
./dist/SAM-VKO-Agent
```

### Windows (.exe)

Выполнить на Windows-машине:
```cmd
cd agent
build_windows.bat
rem Результат: dist\SAM-VKO-Agent.exe
```

Запуск: двойной клик на `SAM-VKO-Agent.exe`.

---

## Автозапуск при старте системы

```bash
# Linux — добавляет desktop-файл в ~/.config/autostart/
./dist/SAM-VKO-Agent --install-autostart

# Windows — добавляет запись в реестр HKCU\Software\Microsoft\Windows\CurrentVersion\Run
dist\SAM-VKO-Agent.exe --install-autostart
```

## Консольный режим (без GUI)

```bash
# Создать конфиг вручную
mkdir -p ~/.vko-agent
cat > ~/.vko-agent/config.json << 'EOF'
{
  "backend": "http://localhost:8000",
  "school_code": "VKO-UK-001",
  "enroll_secret": "КОД_РАЗВЕРТЫВАНИЯ",
  "room": "Серверная",
  "verify_tls": false
}
EOF

# Запустить без GUI
python tray_agent.py --console
```

## Меню трея

| Пункт | Действие |
|---|---|
| Показать статус | Открыть окно с текущими метриками |
| Открыть панель | Открыть веб-интерфейс в браузере |
| Настройки | Изменить сервер, школу или код |
| Перезапустить агент | Переподключиться к серверу |
| Завершить | Выйти из программы |

---

## Состояния иконки

| Цвет | Значение |
|---|---|
| Зеленый | Норма — параметры в пределах SLA |
| Желтый | Нестабильно — скорость ниже 10 Мбит/с или потери выше 5% |
| Красный | Нет соединения с сервером |
| Серый | Инициализация или замер |
