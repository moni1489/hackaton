# САМ ВКО — Трей-агент (Windows & Linux)

Приложение в системном трее для сбора данных о качестве интернета на школьном ПК.
Работает в фоне, отправляет замеры на сервер, хранит данные офлайн при обрыве связи.

---

## Что умеет

- 🟢 **Иконка в трее** — меняет цвет в зависимости от состояния (зелёный / жёлтый / красный)
- 📊 **Окно статуса** — показывает текущие ↓ Download, ↑ Upload, Ping, Packet Loss
- ⚙️ **Диалог настройки** — адрес сервера, код школы, код развёртывания
- 📡 **Speedtest** — реальный замер через `speedtest-cli`
- 💾 **Офлайн-спул** — при обрыве замеры сохраняются локально в SQLite, потом автоматически выгружаются
- 🔄 **Автозапуск** — одна команда добавляет агент в автозагрузку системы
- 🌐 **Кнопка «Открыть панель»** — открывает браузер с админ-дашбордом

## Быстрый старт (без сборки)

### Требования
- Python 3.9+
- `speedtest-cli` в PATH (или установить ниже)

### Linux

```bash
cd agent

# Установить зависимости
pip install -r requirements-tray.txt
pip install speedtest-cli

# Запустить
python tray_agent.py
```

### Windows

```cmd
cd agent

# Установить зависимости
pip install -r requirements-tray.txt
pip install speedtest-cli

# Запустить
python tray_agent.py
```

**При первом запуске** откроется окно настройки:

| Поле | Значение |
|---|---|
| Адрес сервера | `http://localhost:8000` (или IP вашего сервера) |
| Код школы | Например `VKO-UK-001` |
| Код развёртывания | Получить в панели: **Управление → Школы → «Код агента»** |
| Кабинет | `Кабинет информатики №1` |

## Сборка в один файл (без Python на целевой машине)

### Linux → бинарник

```bash
cd agent
bash build_linux.sh
# Результат: dist/SAM-VKO-Agent
```

Запуск на любой Linux-машине:
```bash
chmod +x dist/SAM-VKO-Agent
./dist/SAM-VKO-Agent
```

### Windows → .exe

Выполнить на **Windows-машине**:
```cmd
cd agent
build_windows.bat
REM Результат: dist\SAM-VKO-Agent.exe
```

Запустить: двойной клик на `SAM-VKO-Agent.exe`

## Автозапуск при старте системы

```bash
# Linux — добавляет .desktop файл в ~/.config/autostart/
./dist/SAM-VKO-Agent --install-autostart

# Windows — добавляет запись в реестр HKCU\...\Run
dist\SAM-VKO-Agent.exe --install-autostart
```

## Консольный режим (без GUI / на сервере)

```bash
# Создать конфиг вручную
mkdir -p ~/.vko-agent
cat > ~/.vko-agent/config.json << 'EOF'
{
  "backend": "http://localhost:8000",
  "school_code": "VKO-UK-001",
  "enroll_secret": "ВАШ_КОД_РАЗВЕРТЫВАНИЯ",
  "room": "Серверная",
  "verify_tls": false
}
EOF

# Запустить без GUI
python tray_agent.py --console
```

## Состояния иконки

| Цвет | Значение |
|---|---|
| 🟢 Зелёный | Норма — скорость в порядке |
| 🟡 Жёлтый | Нестабильно — скорость < 10 Мбит/с или потери > 5% |
| 🔴 Красный | Нет соединения |
| ⚪ Серый | Инициализация / ожидание |

## Файлы агента

```
~/.vko-agent/
  config.json     — настройки (адрес сервера, код школы)
  state.json      — токен устройства после регистрации
  spool.sqlite    — офлайн-очередь замеров
  agent.log       — журнал работы
```

## Зависимости

```
requests>=2.32      HTTP к серверу
pystray>=0.19       иконка в трее (Linux: X11/AppIndicator, Windows: Win32)
Pillow>=10.0        рисование иконки
speedtest-cli>=2.1  замер скорости
```

---

## Как работает

```
Старт → Диалог настройки (первый раз)
      → Регистрация на сервере (POST /api/agent/enroll)
      → Получение токена устройства
      → Цикл каждые 15 мин (или по конфигу с сервера):
          1. speedtest-cli --json   → скорость
          2. ping 8.8.8.8 -c 10    → потери и джиттер
          3. POST /api/agent/measurements  → отправка
             ↳ если сервер недоступен → сохранить в spool.sqlite
             ↳ при восстановлении → batch-выгрузка спула
```
